# EANM contingency scenarios — GitHub Pages package

This folder is ready to upload to a GitHub repository.

## Files

- `index.html` — mobile-friendly landing page with links to all three scenarios
- `transport.html` — Transport Emergency scenario
- `cyber.html` — Cyber Incident scenario
- `i131.html` — I-131 Patient Emergency Transfer scenario

The Transport and Cyber copies include an added phone-responsive CSS layout.
The scenario content and JavaScript logic have otherwise been retained.

## Publish with GitHub Pages

1. Create a new GitHub repository.
2. Upload all four HTML files from this folder to the repository root.
3. Commit the files to the `main` branch.
4. Open **Settings → Pages**.
5. Under **Build and deployment**, choose **Deploy from a branch**.
6. Select **main** and **/(root)**, then save.
7. GitHub will provide a Pages URL, typically:
   `https://YOUR-USERNAME.github.io/YOUR-REPOSITORY/`

Use that main URL for one QR code. It opens the landing page, where attendees can choose among the three scenarios.

## Before putting the QR code on the poster

- Open the Pages URL on both iPhone and Android if possible.
- Test every scenario from beginning to end.
- Test using mobile data as well as Wi-Fi.
- Remember that a normal GitHub Pages site is public. Do not publish real patient-identifiable, confidential, or operationally sensitive information.
- Keep the final repository name stable after generating the QR code, because changing it changes the URL.
